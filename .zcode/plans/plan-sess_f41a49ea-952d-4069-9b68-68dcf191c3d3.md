# Làm lại bộ kỹ năng anh hùng — 1 đánh thường (Q) + 3 kỹ năng hệ phái (E/R/F) + animation hoàn chỉnh

## 1. Thiết kế bộ kỹ năng mới (tất cả tên/cơ chế mới, palette theo hệ phái)

Mỗi hero có trường `hePhai {name, color}` hiển thị ở màn chọn + HUD. Cấu trúc mỗi skill mới: `key, cd, mp, pot, range, cast, aoe, dot, stun, slow, heal, shield, buff, dash, taunt, chain, fx{type,color}` — phần lớn hành vi chạy data-driven, hết kiểu switch cứng như cũ.

**PALADIN — Hệ Thánh Quang** (vàng gold)
- **Q · Trảm Kiếm** — cận chiến 135, cd 0.9s, miễn phí. Mỗi đòn thứ 3 cộng hưởng +60% dmg, shockwave vàng to hơn.
- **E · Ném Khiên** — cd 6s, tầm 450. Bay ra trúng địch (190 pot, tăng thù hận) rồi **bay về** tay tướng.
- **R · Thánh Chánh Trảm** — cd 12s. Nhảy lao tới địch, AoE 120 (260 pot) + choáng 1s.
- **F · Thánh Khiên Bất Diệt** — cd 45s (ult). Bất tử 5s + khiên vàng vòm tròn + khiêu chiến mọi địch gần.

**WHITE MAGE — Hệ Thiên Nhiên** (xanh lá)
- **Q · Phi Thạch** — tầm 500, cd 1.1s, miễn phí. Đá bay có vệt bụi.
- **E · Cuồng Phong** — cd 7s. Vòng xoáy gió quanh địch: 90 pot + DoT gió 8s, lá xoay tỏa quanh mục tiêu.
- **R · Thánh Quang** — cd 13s, đọc 1.6s. AoE quanh mình 180: 240 pot + choáng 1.2s, cột sáng khổng lồ.
- **F · Mệnh Thiên Hội Phục** — cd 60s (ult). Hồi 45% HP cả đội + khiên 15%, **hồi sinh đồng đội đã chết 40% HP**, cột sáng từng người.

**BLACK MAGE — Hệ Nguyên Tố** (đỏ lửa chủ đạo, phụ băng/lôi)
- **Q · Hỏa Tiễn** — tầm 520, cd 1.1s, miễn phí. Cầu lửa nhỏ nổ tung.
- **E · Băng Thuật** — cd 8s, đọc 1.2s, **hồi 25% MP**. Mưa băng giáng xuống: 190 pot + làm chậm 20%/4s.
- **R · Lôi Phạt** — cd 12s, đọc 1.5s. Tia sét từ trời giáng xuống: 210 pot + DoT sét 10s.
- **F · Diệt Tinh Hỏa Ngục** — cd 40s (ult), đọc 2.2s. AoE 170 tại mục tiêu: 380 pot, vụ nổ + mưa thiên thạch + rung màn hình.

**MONK — Hệ Chân Khí** (cam đỏ)
- **Q · Liên Hoàn Cước** — cận chiến, cd 0.75s (nhanh nhất), miễn phí. Chuỗi đòn: đấm → đấm → đá (+40%, lao xa hơn).
- **E · Cương Quyền** — cd 7s. Giật tay đấm_shockwave: 240 pot + choáng 1s.
- **R · Hỏa Hầu Quyền** — cd 14s. Buff 10s: +25% dmg, +15% tốc đánh, aura lửa cháy quanh người.
- **F · Phong Thần Cước** — cd 30s (ult). Bay khoé xuyên qua địch 320 pot + choáng 1.5s, để lại vệt afterimage, đáp sau lưng địch.

Skill cũ bị bỏ: hallowedGround, lucidDreaming, manaward, steelPeak, shoulderTackle... (thay thế bằng bộ trên). Combo 1-2-3 cũ gỡ bỏ — nhịp đánh dồn vào Q. Auto-attack tự động của player bỏ (đồng đội NPC giữ nguyên).

## 2. Phím & HUD
- Bàn phím: `Q` đánh thường, `E`/`R`/`F` = 3 kỹ năng hệ phái, `Z` thuốc, `C` counter, `X` Limit Break, giữ nguyên WASD/P.
- HUD mobile: cung nút phải vẽ lại thành 4 nút **Q (to nhất hoặc theo vị trí chuẩn MOBA), E, R, F** — nhãn phím trên nút, viền màu hệ phái, sweep cooldown từng nút, nút F to hơn (ult).
- Màn chọn hero + khung player: thêm badge tên hệ phái + màu.

## 3. Hệ thống animation/VFX mới (trái tim của task) — file mới `js/fx.js`
Xây lớp hiệu ứng generic (mỗi fx là object `{type, t, tmax, ...}` có update/draw riêng, tái dùng pattern `{t,tmax}` sẵn có của `G.parts/rings`):
- **charge** — lúc đọc thần chú: pháp阵 circle dưới chân lớn dần + hạt mana hội tụ vào người.
- **act anim trên nhân vật** — `p.act = {kind: slash|punch|kick|cast|toss}` : lao về phía mục tiêu theo sin, scale pulse, vũ khí/vòng sáng lóe; HẾT cảnh "đứng yên nhìn vào hư không".
- **pillar** — cột sáng (Thánh Quang, heal, hồi sinh).
- **nova / shockwave** — vòng sóng xung kích + bụi (impact chung, Thánh Chánh Trảm).
- **boltstrike** — tia sét zigzag từ trời (Lôi Phạt).
- **vortex** — hạt xoay tròn quanh điểm (Cuồng Phong, DoT ticks màu nguyên tố).
- **aura / dome** — glow bám theo entity theo thời gian buff (Hỏa Hầu Quyền, Thánh Khiên).
- **trail/afterimage** — vệt bay (Phong Thần Cước, các dash).
- Nâng cấp `addSlash` thành slash nhiều cung màu tùy hệ; projectile có **trail hạt** theo nguyên tố + vụ nổ khi trúng.

## 4. Sửa file
1. `js/data.js` — SKILLS + JOBS mới hoàn toàn theo thiết kế trên.
2. `js/fx.js` (mới, khai báo trong `index.html`) — hệ fx ở mục 3.
3. `js/entities.js` — `tryUseSkill`/`applySkill` viết lại data-driven theo `def.fx.type` + handler heal/shield/buff/dash/taunt/stun/slow/revive; logic chuỗi đòn Q; `p.act` + charge; bỏ auto-attack player; cooldown thuần cho E/R/F.
4. `js/input.js` — map phím mới.
5. `js/world.js` — vẽ act anim/lao/charge lên player, layer fx, vệt dash, icon DoT nguyên tố.
6. `js/hud.js` — 4 nút Q/E/R/F nhãn phím + màu phái, badge hệ phái, khung player.
7. `README.md` — bảng điều khiển mới.
- Không đụng boss (Ifrit/Titan), đồng đội NPC, enmity, telegraph.

## 5. Kiểm thử
- Chạy `python3 -m http.server`, chơi thử cả 4 hero bằng browser automation: bấm từng phím Q/E/R/F, chụp ảnh xác nhận mỗi skill CÓ hiệu ứng nhìn thấy được (projectile có vệt, sét giáng, cột sáng, aura...), cooldown/GCD đúng, không lỗi console.
- Kiểm tra cả 2 boss vẫn hoạt động bình thường với damage mới.
